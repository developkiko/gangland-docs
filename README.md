# GangLand Web

Web-порт GangLand (MediaMob, 2004). Ремейк на TypeScript: ассеты оригинала извлекаются
локально из GOG-версии, игровой код пишется с нуля. Стратегия и обоснование — [PORTING.md](PORTING.md).

> ⚠️ Ассеты принадлежат правообладателю игры. Извлечение — только для личной разработки.
> Публиковать извлечённое нельзя.

## Быстрый старт

Нужен Node.js 18+.

```bash
npm install
npm run extract   # извлечь .lfm-архивы из ../Data → extracted/ + public/assets-index.json
npm run dev       # http://localhost:5173 — Asset Browser
```

## Что уже работает (фаза 0)

- **Парсер контейнера `.lfm`** — формат восстановлен полностью:
  `[uint32 BE: смещение данных][uint24 BE: число записей]`, каталог `[имя\0][uint32 BE размер]`,
  далее блоки данных в порядке каталога. Все 7 открытых архивов сходятся байт-в-байт.
- **Экстрактор** (`tools/lfm-extract.mjs`): 7 архивов, ~10 400 файлов, ~288 MB → `extracted/`:
  | Архив | Файлов | Содержимое |
  |---|---|---|
  | user_interface | 684 | 659 PNG (браузер показывает напрямую) + DDS |
  | sound | 1825 | 1748 OGG + 77 WAV (играются браузером) |
  | game_textures | 2748 | DDS-текстуры (превью прямо в браузере) |
  | models | 1253 | .mmo-модели + .mmc (формат на разбор) |
  | animation | 1651 | .vta-анимации (формат на разбор) |
  | fonts | 108 | .mmf-шрифты |
  | effect_textures | 190 | DDS-эффекты |
- **Декодер DDS** (`src/lib/dds.ts`, DXT1/DXT3/DXT5 → RGBA): все текстуры игры
  открываются прямо в Asset Browser. Корректность проверена визуально на HUD и интерьерах.
- **Карты кампании вырезаны** (`tools/carve-maps.mjs`): каталог `maps.lfm` зашифрован,
  но блоки данных открытые — все **37 карт FWMP** извлечены в `extracted/maps_carved/`
  вместе с оригинальными путями-именами (`Vegas`, `little_italy`, `Poor`, `Docks`, `Ninja`).
  В заголовке FWMP: версия 4, исходный .ini, размер сетки (например, 76×74).
  Формат дальше — записи объектов (здания/дороги, float-координаты); земля генерируется
  из TileObjects INI, а не хранится в карте — полный парсер после расшифровки.
  Заодно найдено кодовое имя движка: **FW** (пути `C:\FW\Data\...`).
- **Каталоги ВСЕХ 12 архивов восстановлены.** Для 5 «зашифрованных» (lua, text, characters,
  maps, locale) имена и размеры получены из памяти запущенного процесса (`tools/recover-from-dump.mjs`,
  дамп: `powershell C:\Meine\tools\dump-mem.ps1`): сумма размеров каждой цепочки сходится
  с размером секции данных файла байт-в-байт. Итог: **1234 файла игры поименованы и отмерены**.
- **94/107 Lua-скриптов игры расшифрованы** (`extracted/lua/**.luac`) — скомпилированный байткод
  Lua 5.0 с кастомной шапкой: логика поведения, ИИ, режимов. Остальные 13 (`icm_*.ini` — тайминги
  контекстных команд) загружаются лениво: добываются повторным дампом после старта миссии.
- **maps.lfm разобран целиком** (`extracted/maps/`, 559 файлов): 37 карт кампании `.fmp`
  (Vegas/Little Italy/Poor/Docks/Ninja — уже с настоящими именами из каталога), 109 ini,
  тайлы/дороги `.cst`/`.wmap`/`.rmp`/`.scm`/`.vis` — всё открытым кодом; 73 map-скрипта `.luac`
  пока шифрованы.
- **Зашифровано остаётся**: `.ini`/`.luac`/`.lcl` блоки (тексты text.lfm, характеристики
  characters.lfm, локаль, map-скрипты). Шифр — не XOR и не MSVC-LCG (проверено по 1177 байтам
  известного открытого текста — шапки .luac). Пути добора: (а) дамп памяти после загрузки
  соответствующего контента (запуск миссии), (б) реверс шифра в Ghidra — теперь есть ~180 КБ
  известных пар «шифртекст↔открытый текст».
- **Asset Browser** (`npm run dev`): список архивов, фильтр, превью PNG / DDS-декод /
  плеер OGG-WAV / текст INI / hex-дамп остальных; вкладки `maps` и `maps_carved`.

## Структура

```
web/
├── src/lib/lfm.mjs        парсер .lfm (общий для Node и браузера)
├── src/lib/dds.ts         декодер DXT1/3/5 → RGBA
├── src/main.ts            Asset Browser (Vite + TS)
├── tools/lfm-extract.mjs  экстрактор открытых архивов + индекс
├── tools/carve-maps.mjs   вырезание карт кампании из maps.lfm
├── tools/recover-from-dump.mjs  восстановление каталогов/скриптов из дампа памяти
├── extracted/             результат извлечения (в .gitignore — не коммитить!)
└── public/assets-index.json  индекс для браузера
```

Путь до игры предполагается `../Data` относительно папки `web` (текущее расположение ок).
