# ASSET-FORMATS.md — форматы ресурсов GangLand

Факты, проверенные на реальных данных (парсеры в `src/lib/`, инструменты в `tools/`).

## Контейнер .lfm

См. [REVERSE-ENGINEERING.md](REVERSE-ENGINEERING.md) §1. Эмпирика:
- имена — ASCII, чувствительны к регистру, встречаются опечатки разработчиков
  (например `shadow_idle`_deteriorated.vta` с бэктиком) — не «чинить» молча;
- первое имя первого каталога в памяти может идти с мусорным байтом-префиксом
  (`kdev/allmaps.luac`) — при восстановлении отрезать.

## Карты .fmp (магия `FWMP`)

```
[0..3]   uint32 LE = 4 (версия)
[4..7]   "FWMP"
[8..11]  uint32 LE — длина пути-исходника
[12..]   путь (ASCII), например "C:\FW\Data\Maps\Vegas\basemap.ini"
[12+len] uint32 LE — размер сетки A
[..+4]   uint32 LE — размер сетки B   (примеры: 20×20 тест, 76×74 Vegas)
[..]     далее нулевая область (десятки–сотни байт), затем переменные записи
```

Тело — векторные записи объектов (здания, дороги; float-координаты, много
значений 0x40333333 ≈ 2.6). Плоской сетки земли в файле НЕТ — рельеф генерируется
движком из TileObjects INI (`data/maps/tileobjects/ground_*.ini`).
Сопутствующие генерируемые файлы: `.rmp` (float 10.62 + списки пар координат),
`.vis` (начинается с B, A — размеров), `.scm` (seek-cover карта, шифрован).

## Скомпилированные скрипты .luac

Шапка (12 байт): `1B 4C 75 61 50 01 04 04 04 06 08 09`
= сигнатура `\x1bLua`, версия **0x50 (Lua 5.0)**, далее нестандартные поля — и **весь
формат чанка модифицирован**: перед source-строкой 10 постоянных байт
(`09 08 B6 09 93 68 E7 F5 7D 41`), константы хранятся с тегами как в 5.0, но поля
функции и инструкции не декодируются ванильной схемой iABC (перебор раскладок
провалился — см. `tools/luac-probe.mjs`). Это кастомная VM MediaMob: декомпиляция
(unluac и аналоги) требует сначала реверса VM (dispatch-цикл luaV_execute в
GangLand.exe через Ghidra) либо нахождения их модифицированных исходников Lua.

## Текстуры .dds

Практически все — **DXT3** (block size 16, `fourCC` на смещении 84), mipmap'ы
в отдельных файлах с суффиксами `_2`, `_4` (половинные разрешения). Декодер:
`src/lib/dds.ts` (DXT1/DXT3/DXT5 → RGBA), проверен визуально на HUD 1024×256.
Примечание: пары `X.dds` и `X2.png` в user_interface — РАЗНЫЕ варианты арта,
не дубликаты (сравнение попиксельно даёт большую дельту — это норма).

## Прочее

- `.mmo` (модели, 1070 шт.) / `.mmc` — формат не разобран; внутри models.lfm также
  лежат TGA-текстуры (пути вида `data/game_textures/buildings/...`).
- `.vta` (анимации, 1651 шт.) — не разобран.
- `.mmf` (шрифты, 108 шт.) — битмап-шрифты, первая запись часто `ansi/arial/14.mmf`.
- `.lcl` (locale.lfm → `default.lcl`, 130860 байт) — формат локализации, шифрован.
- `.wmap` — проходимость тайлов, `.cst` — конструкции зданий, `.rmp`/`.scm`/`.vis` —
  генерируемые навигационные слои карт.
- Звук: `.ogg` (музыка/речи) и `.wav` (эффекты) — играются браузером напрямую.
- Видео/музыка меню: `Data/streams/*.ogg`.

## Инвентарь (12 архивов, 1234 именованных файлов в шифрованных + ~8400 в открытых)

Полные каталоги: `C:\Meine\tools\dirs\*.json` (после запуска
`node tools/recover-from-dump.mjs`), локальная копия индекса — `public/assets-index.json`
(генерируется, в git не входит).

## Юридическое

Все ресурсы принадлежат правообладателю игры. Извлечение — только локально, для
личной разработки. В репозиторий ассеты не попадают (`extracted/` и
`public/assets-index.json` в `.gitignore`).
