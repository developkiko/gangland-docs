# REVERSE-ENGINEERING.md — как вскрывался GangLand

Хронология и методы реверс-инженерии GOG-версии GangLand (MediaMob Studios, 2004).
Всё описанное выполнялось бесплатными инструментами на Windows 10 + Git Bash + Node 24.

## 1. Контейнер .lfm — формат восстановлен полностью

```
[0..3]  uint32 BE — смещение секции данных (конец каталога)
[4..6]  uint24 BE — число записей
[7..]   каталог: N записей вида  [имя ASCII, NUL-терминированное][uint32 BE размер]
[dataOffset..конец] — блоки данных, конкатенированы в порядке каталога
```

Парсер: `src/lib/lfm.mjs`. Валидация: для всех 7 открытых архивов
`смещение_данных + сумма(размеров) == размер_файла` — точное совпадение.

| Архив | Записей | Данные | Каталог |
|---|---|---|---|
| user_interface | 684 | открыто (659 PNG, 24 DDS, 1 INI) | открыт |
| sound | 1825 | открыто (1748 OGG, 77 WAV) | открыт |
| game_textures | 2748 | открыто (DDS DXT3) | открыт |
| models | 1253 | открыто (.mmo ×1070, .mmc ×183) | открыт |
| animation | 1651 | открыто (.vta) | открыт |
| fonts | 108 | открыто (.mmf) | открыт |
| effect_textures | 190 | открыто (DDS) | открыт |
| **lua** | 107 | шифровано | шифрован → восстановлен из памяти |
| **text** | 314 | шифровано (.ini) | шифрован → восстановлен из памяти |
| **characters** | 80 | шифровано (.ini) | шифрован → восстановлен из памяти |
| **maps** | 559 | частично открыто (.fmp/.cst/.wmap/.rmp/.scm/.vis), .ini/.luac шифрованы | шифрован → восстановлен из памяти |
| **locale** | 2 (default.lcl 130860 + settings.ini 25) | шифровано | шифрован → восстановлен из памяти |

Шифр покрывает только «текстовые» форматы (.ini/.luac/.lcl); бинарные игровые данные
хранятся как есть. Отсюда энтропия 7.71 бит/байт у lua.lfm — это байткод, а не шифр.

## 2. Что не сработало (чтобы не повторять)

- Повторяющийся XOR любой длины: пер-позиционная статистика по каталогу characters.lfm
  дала ложные срабатывания, известные подстроки (GUNMAN, characters.ini, .lua) не находятся.
- Гистограммы частот шифрованных каталогов плоские (~3% на байт) — псевдослучайный поток.
- inflate/inflateRaw по всему файлу и по смещениям 4–40 — не zlib-контейнер.
- Экстракция MSVC LCG (`state = state*0x343FD + 0x269EC3`, `out=(state>>16)&0x7FFF`)
  по 11 байтам известного открытого текста на блок (шапки .luac): перебор всех 2¹⁶
  скрытых бит состояния × 33 варианта экстракции (XOR/ADD, state>>0..31, out>>0..7) —
  ни один не дал непрерывность потока между блоками.
- Поиск загрузчика через строки: единственная строка `"%s.lfm:"` (VA 0x69CEBF) не имеет
  статических xref-ов (string pooling / косвенная адресация).

## 3. Что сработало: динамический дамп памяти

Игра сама расшифровывает каталоги при старте и блоки данных при чтении — снимаем готовое.

1. `Renderers/RendererOGL.ini` → `Fullscreen = 0`, 800×600 (после — восстановить!).
2. Запустить `GangLand.exe`, дождаться меню (~60–90 сек; рабочая память вырастает до ~220 МБ).
3. `powershell C:\Meine\tools\dump-mem.ps1 -OutDir C:\Meine\tools\memdump`
   (ReadProcessMemory по всем MEM_COMMIT-регионам; 776 регионов, ~411 МБ).
4. `node web/tools/recover-from-dump.mjs C:\Meine\tools\memdump` — находит в регионах
   цепочки `[имя\0][uint32 BE размер][флаг 01]` и сопоставляет их с .lfm по точной сумме;
   расшифрованные .luac вырезаются по сигнатуре `1B 4C 75 61` в порядке каталога.

Результаты: каталоги всех 5 архивов (суммы сходятся байт-в-байт), 94/107 Lua-скриптов.
Оставшиеся 13 (`icm_*.ini`) и тексты/характеристики загружаются лениво — добираются
дампом **после старта миссии**.

## 4. Ghidra headless (что тоже пригодилось)

Установка без GUI: распаковать [Ghidra](https://github.com/NationalSecurityAgency/ghidra/releases)
+ [JDK 21 Temurin](https://adoptium.net) в `C:\Meine\tools`. Скрипты — в `tools/ghidra/`.

```bash
# импорт + автоанализ (~5–10 мин) + пост-скрипт
./ghidra/support/analyzeHeadless.bat C:/Meine/tools/ghidra_proj GangLand \
  -import C:/Meine/gangland-online/GangLand.exe \
  -scriptPath C:/Meine/gangland-online/web/tools/ghidra \
  -postScript FindLfmLoader.java
# повторные запуски по уже проанализированному проекту
./ghidra/support/analyzeHeadless.bat C:/Meine/tools/ghidra_proj GangLand \
  -process GangLand.exe -noanalysis \
  -scriptPath ... -postScript DecompAt.java 0x00438e34 ...
```

Находки статического анализа:
- exe: 32-bit i386, не запакован; вшиты Lua 5.0, zlib 1.1.4, FMOD 3.x, GameSpy/DirectPlay.
- рендереры: `RendererD3D.DLL` (D3D8), `RendererOGL.DLL` (OpenGL immediate mode) — сменные.
- свой глобальный PRNG: `FUN_006412b6` = rand, `FUN_006412ac` = srand(состояние @ DAT_0069FD50).
- кодовое имя движка — **FW** (исходные пути карт `C:\FW\Data\Maps\...`).
- `editor.exe` — пустая обёртка над cmd.exe, бесполезен для реверса форматов.

## 5. Известные пары «шифр↔открытый текст» (задел на взлом)

94 расшифрованных .luac + их шифртекст в lua.lfm ≈ 180 КБ попарных данных с известными
глобальными смещениями. Для аналитика шифра это лучший вход: проверить поточные шифры
(xorshift, RC4, custom LFSR) на первом блоке и экстраполировать. Альтернатива без взлома —
повторные дампы после загрузки нужного контента в игре.
